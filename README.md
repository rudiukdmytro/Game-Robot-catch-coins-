# Game-Robot-catch-coins-

A simple 2D arcade game built with Python and Pygame. Control a robot at the bottom of the screen to catch falling coins while dodging dangerous obstacles. 

## Gameplay & Rules
- **Objective:** Collect as many coins as possible and survive as long as you can (tracked by the top timer).
- **Coins:** +1 point to your score.
- **Rocks:** -5% health.
- **Monsters:** -10% health.
- **Game Over:** The game ends when your health reaches 0%.

## Controls
- **Left Arrow (`←`):** Move left
- **Right Arrow (`→`):** Move right
